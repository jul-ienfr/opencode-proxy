# Preuve — disponibilité de `deepseek-v4.1-flash-free` (429 par IP) — 2026-11-23

**Feature** : `024-audit-optimisation-globale` — lot de correction free (429).
**Objet** : établir, par un test **par IP**, si le modèle free `deepseek-v4.1-flash-free`
répond ou non, et distinguer un défaut de modèle d'un quota d'IP.

**Commande** (script versionné, wire 2.2.5 exact, `Authorization: Bearer public`,
session `ses_` mintée par le producteur officiel — aucun compte, aucun token) :

```text
python scripts/test_free_egress.py --model deepseek-v4.1-flash-free --repeat 1 --timeout 40
python scripts/test_free_egress.py --station N --model deepseek-v4.1-flash-free --repeat 1 --timeout 40
```

## Lecture (règles projet AGENTS.md §0, non négociables)

- **Le modèle est vivant.** Trois egress WARP distincts renvoient **200 avec
  contenu streamé** et l'écho `model=deepseek-v4.1-flash-free`. Le défaut n'est
  donc **pas** le modèle free.
- **Le quota est par IP.** Les `429 FreeUsageLimitError` portent un `Retry-After`
  réel (~4 h 3 min) : les IP NordVPN des stations 3/4/5 et l'IP du poste sont
  **épuisées**, pas le compte, pas la flotte.
- **Trois stations ont un tunnel cassé**, pas un quota : 1/2/6 échouent au
  niveau SOCKS5 (`curl 97`), avant toute réponse HTTP.
- **Il existe des IP qui répondent 200** (WARP). Une série d'échecs sur une IP
  ne vaut **pas** pour l'ensemble du pool : ce relevé ne conclut rien sur les
  centaines d'IP disponibles.

## Conséquence pour le plan

La correction ne porte pas sur l'accès au modèle (prouvé 200) mais sur :
1. la **réparation des tunnels** des stations 1/2/6 (échelle de transports) ;
2. la **classification honnête** des 429 en `quota` avec `reset_at` (jamais un
   faux « modèle indisponible ») ;
3. la **bascule automatique** du trafic client vers une IP prouvée 200 (WARP
   aujourd'hui) tant que les IP NordVPN sont `spent`.

Ces trois volets sont alignés sur `023-client-usable-egress` (§2.3 admission,
`classify_429`, §9 providers) et sur `024` (Phase 1 « restaurer la capacité de
la flotte », principe X « dégradation explicite »).
